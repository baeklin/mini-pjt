# 표준 예방접종 일정 (생후 0~24개월)

## 요약
국가예방접종은 12세 이하 어린이가 대상이며, 필수 예방접종 비용은 국가가 지원한다. 아래는 생후 0~24개월에 해당하는 접종이다.

## 월령별 접종 일정

| 권장 시기 | 백신 | 차수 |
|---|---|---|
| 출생 시 | B형간염(HepB) | 1차 |
| 생후 4주 이내 | 결핵(BCG, 피내용) | 1회 |
| 1개월 | B형간염(HepB) | 2차 |
| 2개월 | DTaP, 폴리오(IPV), Hib, 폐렴구균(PCV), 로타바이러스(RV) | 각 1차 |
| 4개월 | DTaP, IPV, Hib, PCV, RV | 각 2차 |
| 6개월 | DTaP, IPV, Hib, PCV, RV | 각 3차 |
| 6개월 | B형간염(HepB) | 3차 |
| 12~15개월 | Hib, 폐렴구균(PCV) | 각 4차 |
| 12~15개월 | 홍역·유행성이하선염·풍진(MMR) | 1차 |
| 12~15개월 | 수두(VAR) | 1회 |
| 12~23개월 | A형간염(HepA) | 1~2차 |
| 12~23개월 | 일본뇌염 불활성화백신(IJEV) 1~2차 또는 약독화생백신(LJEV) 1차 | 둘 중 하나 선택 |
| 15~18개월 | DTaP | 4차 |

## 참고 사항
- DTaP, IPV, Hib, B형간염은 4가·5가·6가 혼합백신으로 접종할 수 있다.
- 로타바이러스 접종비 지원 기한: 1차는 생후 14주 6일까지, 2~3차는 생후 8개월 0일까지.
- 경피용 BCG는 국가 지원 대상이 아니다.
- 정확한 접종 가능 여부와 아이별 접종 이력은 예방접종도우미(nip.kdca.go.kr)나 접종 기관에서 확인한다.
